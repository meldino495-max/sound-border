# 声浪边框

Chrome / Edge 扩展。识别标签页**输出**的声音，并可选识别麦克风**输入**。

## 输出识别

某个网页打开过输出后会记住。下次再打开这个网站，出声时页面四边的光边会自动出现，像河流一样流动，声音停止后消失。没有打开过的网站保持关闭。不会把标签放进分组。

## 输入识别（默认关）

在弹窗里按网站打开。打开过的网站会被记住，下次再打开这个网站时自动恢复。输入识别会再弹出一个窗口用来允许麦克风。只监听这个浏览器的麦克风，不录音、不上传。

连续一段时间没有输入声音时：

- 每个普通网页，以及地址是 `chrome-extension://` 的本地插件页面，四边都会变红并一直抖动
- 浏览器弹出系统通知

麦克风重新有声音后，红边和通知消失。弹窗里的「停止本次输入识别」只取消这一次的红边和监听，不会忘掉网站。下次再打开那个网站，输入识别会自动打开。灵敏度、无声多久才提醒，都可以在弹窗里改。

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`
2. 打开「开发者模式」
3. 「加载已解压的扩展程序」，选这个 `声浪边框` 文件夹
4. 点工具栏图标。输入识别要允许麦克风

已经打开的网页会自动挂上。若某个页面没有反应，刷新一次。

## 做不到的事

扩展改不了浏览器窗口外面那圈系统边框，也不会给标签分组。流动光边画在网页四边。

`chrome://`、`edge://`、新标签页和应用商店不允许扩展画上去。这些页面上看不到光边。本地插件自己的 `chrome-extension://` 页面可以画红边；重新加载扩展时要允许新增的调试权限。若浏览器拦住，打开 `chrome://flags` 或 `edge://flags`，把 `silent-debugger-extension-api` 设成 Enabled，然后重启浏览器。
